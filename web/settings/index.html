DMX output

Where Light Runner sends the commands for the lights.

Turn Send DMX off while another desk (for example Lightkey) controls the lights. Light Runner keeps running and the stage view keeps working.

This server was started with DMX output forced off (LIGHT_RUNNER_OUTPUT=none), so nothing is sent whatever you choose here.

Operator page

What the volunteers' page lets them do.

Basic lights is set from the operator page: start it, set the stage, then hold Save.

Who to call

Shown to the volunteers when the lights have a problem. Left out when empty.

OSC

Let other programs, like ProPresenter, control the lights.

They send messages over the network to this computer, such as /lightrunner/next or /lightrunner/group/2/level 0.5.

8000 unless the other program needs another.

Controller keys

What the keys, faders and knobs on a MIDI controller do. Tap Assign a key, then press the key on the controller.

MIDI support isn't installed on this computer, so controllers can't be used. Run npm install in the Light Runner folder on this computer, then start Light Runner again.

Devices

Controllers plugged into this computer are found within a few seconds. Light Runner listens to each one that is switched on.

APC mini layout

Faders 1–8 dim the groups and fader 9 is Master. The top two rows of pads start the running order by place, the rows below pick each group's colours. A key you assign on the APC mini does its new job instead.

Songs and quick looks get their keys where they are edited on the operator page: Edit list, and a quick look's Edit.

Engine

How often the lights are updated, and how fades look near dark.

2.2 makes slow fades look even near dark. 1 is linear.

Fixture database

Free fixture definitions, so Patch can find fixtures without internet.

The Open Fixture Library has DMX definitions for hundreds of fixtures. Download it once and the Patch page can browse and search it without internet.

        Fixture types already in your show keep their channels. To use a changed definition, add it again from Patch.
