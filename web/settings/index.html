Operator page

Basic lights is set from the operator page: start it, set the stage, then hold Save.

OSC

Let other programs (like ProPresenter) control the lights over the network. They send messages such as /lightrunner/next or /lightrunner/group/2/level 0.5 to this computer.

8000 unless the other program needs another.

APC mini

APC mini: not connected

Plug an Akai APC mini into this computer and it is found within a few seconds. Faders 1–8 dim the groups and fader 9 is Master. The top two rows of pads start the songs, the rows below pick each group's colours.

Engine
