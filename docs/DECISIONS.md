# Decisions

Choices made while building Light Runner, newest first, with the reason. Add an entry whenever the build departs from [SPEC.md](SPEC.md) or a choice would surprise someone reading the code.

| 2026-10-21 | A held light's UV is taken out before it is mixed on a fixture without UV, as a preset's already was. | The jump check, given held colours with UV, found a 7.8 % step: the UV the bar can't make set the mix's brightness until blue overtook it. |
| 2026-10-21 | **An edit made in Prepare never changes the lights** (the owner's ruling, and the controller's for Blackout). A show edit from a tablet in Prepare (a colour's colour, brightness, White, Amber or UV, shared or for every group of that name; an effect's settings; any edit that changes how a colour or effect looks) is applied with the lights kept: every live group showing a changed colour or effect, and every group whose colour Blackout will bring back, is pinned to a hidden copy of it as it was (palette colours looked up, brightness and fade kept; `keepLitPresets`, which uses again a hidden copy with the same light, name and fade), and the engine moves the group onto it with no fade (an effect carries on from where it is), with Blackout's memory and the Undo steps that name the colour; a run still fading out keeps its old definition under a spare key, so it fades out as it was and the next use takes the edit. The draft takes the edit at once. The stage reads as changed until it next takes that colour (Next, a song, Back to saved, a colour tap; Go when the draft has the edited colour: started before the edit, or a song or the colour tapped in Prepare after it). Undo from Live takes back the edit and moves those groups back onto their own colour, which looks the same again, so the lights never move. Edits made in Live change the lights as before. Any colours and live effects are never pinned: no show edit changes them. The server takes the stage and the show it runs together (taken again if another edit was on its way) and the engine refuses a pin for a group that moved on; a group that starts the colour in that same instant takes the edit with a fade. | A volunteer preparing the next song could otherwise change the lights under the current one; Prepare's own Undo couldn't take that back. Blackout's memory is kept too so that coming back from Blackout shows exactly what was lit. |

| 2026-10-20 | **Individual lights after review** (the controller's ruling and the review's fixes). (1) **Blackout:** while it is on, the panel's colour circles, Any colour, Level, Release picked and Release all are unavailable, with a quiet "Blackout is on.
